Hyperstar GPS Notation

Letter-based recursive ordinal notation.

Current Extensions

  • GPS Notation
  • GPSX Notation

TAD

  • % denotes the remaining expression (can be null)
  • [] denotes power of the expression
  • greek letters denote ordinals
  • \(P(\%,0)=g\%\)
  • \(P(\%,\nu+1)=P(p\%,\nu)\)
  • \(P(\%,\nu)=sup_{\lambda\lt\nu}P(p\%,\lambda)\), only if ν limit ordinal

GPS Notation

  1. \(\% = \%[0]\)
  2. \(\varnothing[\nu] = \nu\)
  3. \((\%[\nu])[\mu] = \%[\nu+\mu]\)
  4. \(g\%[\nu] = \%[\nu+1]\)
  5. \(p\%[0] = \%\)
  6. \(p\%[\nu+1] = p(\%[\omega])[\nu]\)
  7. \(p\%[\nu] = sup_{\lambda\lt\nu}p\%[\lambda]\), only if ν limit ordinal
  8. \(s\%[0]=\%\)
  9. \(s\%[\nu+1] = sP(\%,\omega)[\nu]\)
  10. \(s\%[\nu] = sup_{\lambda\lt\nu}s\%[\lambda]\), only if ν limit ordinal

GPSX Notation

  1. \(X_0(\%,0) = g\%\)
  2. \(X_0(\%,\nu+1) = X_0(p\%,\nu)\)
  3. \(X_0(\%,\nu) = sup_{\lambda\lt\nu}X_0(\%,\lambda)\), only if ν limit ordinal
  4. \(X_{\mu+1}(\%,0) = g\%\)
  5. \(X_{\mu+1}(\%,\nu+1) = X_{\mu+1}(x_{\mu}\%, \nu)\)
  6. \(X_{\mu+1}(\%,\nu) = sup_{\lambda\lt\nu}X_{\mu+1}(\%,\lambda)\), only if ν limit ordinal
  7. \(X_{\mu}(\%,0) = g\%\)
  8. \(X_{\mu}(\%,\nu+1) = sup_{\lambda\lt\mu}X_{\lambda}(\%,\nu+1)\), only if μ limit ordinal
  9. \(X_{\mu}(\%,\nu) = sup_{\lambda\lt\mu}X_{\lambda}(\%,\nu)\), only if μ limit ordinal
  10. \(x_0\%[0]=\%\)
  11. \(x_0\%[\nu+1] = x_0X_0(\%,\omega)[\nu]\)
  12. \(x_0\%[\nu] = sup_{\lambda\lt\nu}x_0\%[\lambda]\), only if ν limit ordinal
  13. \(x_{\mu+1}\%[0]=\%\)
  14. \(x_{\mu+1}\%[\nu+1] = x_{\mu+1}X_{\mu+1}(\%,\omega)[\nu]\)
  15. \(x_{\mu+1}\%[\nu] = sup_{\lambda\lt\nu}x_{\mu+1}\%[\lambda]\), only if ν limit ordinal
  16. \(x_{\mu}\%[0]=\%\)
  17. \(x_{\mu}\%[\nu+1] = x_{\mu}X_{\mu}(\%,\omega)[\nu]\)
  18. \(x_{\mu}\%[\nu] = sup_{\lambda\lt\mu}x_{\lambda}\%[\nu]\), only if μ limit ordinal
